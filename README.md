# EVÐA releases

Built installers for the EVÐA app, and the manifest an installed copy reads to learn an update exists.

**[Download the latest release](https://github.com/mikedouzinas/evda-releases/releases/latest)** — macOS, universal (Apple silicon and Intel), signed and notarized, so it opens without a warning.

An EVÐA is a folder of plain files on your own machine: your record in your own words, a ledger of claims about you and what happened to each one, and the instructions an agent needs to operate it with no other context. Nothing leaves the folder.

If you would rather start from a terminal, `npx create-evda my-evda` does the same thing.

There is no source here. This repository holds release artifacts only.
